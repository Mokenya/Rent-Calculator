*Rent Calculator*

*Description:
This program is called Rent Calculator. In order to run this program, user must use visual studio code. The language used for the program is python. Users must ensure to install python packages in order for the program to run.

The program is designed for users who are sharing rental apartments.

These are the following program entails:

*Input=
The user must enter the rental amount
The user must enter the water bill amount
The user must enter the electricity bill amount
The user must enter the groceries bill amount
The user must enter the number of sharing the apartment

*Output=
Grand Total Monthly Cost will be visible
The grand total will be divided into each category and number of sharing
per unit.
